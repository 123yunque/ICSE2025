## 论文分析：REval (ICSE2025)

- 对论文 "Reasoning Runtime Behavior of a Program with LLM: How Far Are We?" 进行了系统性分析
- 论文提出 REval 框架，评估 LLM 对程序运行时行为的推理能力
- 四类任务：CCP（语句覆盖）、PSP（变量状态）、EPP（执行路径）、OP（输出预测）
- 核心创新：Incremental Consistency（增量一致性），检测"猜对答案但推理错误"的现象
- 关键发现：所有模型平均准确率仅 44.4%，EPP 最难（19.4%），GPT-4-Turbo 领先（75.0%）
- 代码生成能力与代码推理能力相关但不等价（Pearson 0.772）
